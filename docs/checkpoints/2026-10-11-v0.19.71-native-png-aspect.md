# PulseDeck v0.19.71/build160 — Restore source PNG aspect across live and MP4

## Symptom and cause
- Phone report 2026-10-11: transparent imported PNG frames rendered "egg-shaped" and FMV logos stretched. User explicitly requested original canvas geometry, not a new reimport or destructive source rewrite.
- Importer `ExternalPngHeroLibrary.decode` uses `BitmapFactory` with `inScaled=false`, preserving native bitmap width and height and retaining transparency and saved SAF source.
- Fault: `HeroBoardView.drawBitmapLayer`, `CyberSharkExportRenderer.drawBitmapLayer`, `EglBitmapEncoderSurface.drawStaticBitmapLayer` forced all image layers onto square output. GPU used a single half-size both axes. This changes the look of rectangular PNGs.
- Fix: pure `BoardBitmapGeometry.fitCanvas` sizes original bitmap within slider extent with preserved W/H ratio. Canvas/CPU `RectF` gets separate W/H; GPU quad gets halfW/halfH. Source pixels, alpha padding, existing size settings and anchor positions remain unchanged. Square PNGs preserve previous geometry exactly.
