## Implementation (source)
1. On both **Board editor** and **Playback Themes** add one clearly labeled section **«Додати свої PNG-шари»** and **three direct buttons**: **«＋ Рамки»**, **«＋ Написи»**, **«＋ Ефекти»**. They invoke `requestExternalPngFolder(GfArtType.FRAME/WORDMARK/FX)` respectively. Buttons automatically wrap their labels within weighted row widths. A direct import skips the **hero-only** chooser entirely.
2. SAF result already stores the exact role synchronously before opening external picker (v151 fix), indexes only that role and returns to `showGfMixSourcePicker(type)`, where the user explicitly selects a newly indexed source. Original CREATURE `items/tree_uri` stay separate; a tree already assigned to a different type is rejected to avoid cross-category overwrites. No original files are copied into APK; package selection is only external persisted URI refs.
3. Long **Board GF Mix and Hero chooser buttons** and **Theme external Hero chooser button** are now `WRAP_CONTENT` height with >= 52dp minimum. Spacing between buttons: 10dp Board, 12–14dp Theme; direct import controls get distinct 8dp inline gaps and sections have spacing. `actionPill` centers wrapped text, adds 12dp horizontal + 10dp vertical padding and quality line-break strategy. Compact layer selector chips retain their 42dp compact height.
4. Hero tile filenames can wrap beyond two lines and tile height expands naturally (no hard 205dp). In hero chooser, filename button can grow beyond prior hard 78dp. Preserve preview aspect and original PNG assets.
5. `PulseDeckDialogs` keeps naturally wrapping actions (remove 3-line cap), increases action vertical gap 8→12dp, and makes >5-action pickers scroll inside 58% viewport height instead of extending below system navigation. `showSingleChoice` ignores the Cancel row rather than treating it as an indexed source (avoid `IndexOutOfBounds`).
6. Does not modify center geometry, composition positioning, runtime/projectM, all prior GF presets/selection metadata, picture assets or MP4 composition/export engine. Whole-app UI-RESP audit still broader backlog.

## How to use on phone
- **Board → Редагувати → Додати свої PNG-шари → ＋ Рамки** → Android folder picker → select a folder containing original **transparent PNG frames only** → grant access → see dialog **«GF Мікс · Рамка»** listing imported frames → select one → Board shows that frame independently from current creature.
- Likewise **＋ Написи** (FARIC / FMV logo standalone transparent PNG) and **＋ Ефекти**. For heroes use the separate **«Зовнішні PNG-герої»** action; current ten already registered and need not be reimported.
- Equivalent three import actions also visible in **Playback Themes**. Do not select original Hero folder for Frame type; app will reject that cross-role folder reuse. If a new folder contains no qualifying transparent PNG (real alpha, PNG header, sizes), imported count may be 0; no JPG or re-drawing accepted.
