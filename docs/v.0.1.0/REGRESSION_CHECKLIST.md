# Regression Checklist

- [ ] App launches.
- [ ] Audio file can be selected.
- [ ] Playback starts/stops exactly once.
- [ ] Seek works.
- [ ] Visual energy follows music.
- [ ] Strong beats produce visible impulse.
- [ ] Background image mode works.
- [ ] Background video loop mode works.
- [ ] Rotation does not duplicate playback/analyzer/renderer.
- [ ] Background/foreground is stable.
- [ ] No obvious frame stalls on test phone.
