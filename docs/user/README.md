# FARIC Music Visualizer — документація користувача

**Основний посібник:** [FARIC_USER_GUIDE_UK.md](FARIC_USER_GUIDE_UK.md)  
**Поточна задокументована APK:** **v0.19.43 / build 132** (Android #603 PASS), редакція посібника **1.0 / 2026-10-08**.  
**Мова:** українська.  
**Цільова аудиторія:** користувач застосунку, а не розробник.

## Що описує посібник

Послідовний практичний маршрут: вибрати локальний аудіофайл → керувати відтворенням → вибрати Playback Theme → налаштувати шари та Board → projectM і його FG → зберегти Composition Set → виконати offline analysis → експортувати PNG / пробний MP4 → знайти файл. Окремо: налаштування PulseDeck, типові проблеми, словник і функції «СКОРО».

## Правило підтримки при майбутніх змінах — обов'язкове

Під час зміни вже описаної можливості або додавання нової user-facing функції **у тому ж релізному workflow**:

1. Звірити фактичні кнопки/назви/шляхи з кодом відповідної збірки та телефонними QA (коли потрібні).
2. Оновити `FARIC_USER_GUIDE_UK.md` — розділ, кроки, пояснення, поточну версію та статус функції.
3. Оновити цей README: номер build, короткий запис про нову редакцію й перелік змінених розділів.
4. Оновити або додати ілюстрації, **відрізняючи реальний APK screenshot від макета/референсу**. Не вигадувати зображення як доказ функціональності.
5. Перегенерувати користувацький PDF/DOCX за потреби й перевірити після рендера (немає обрізань/перекриттів, усі табличні рядки читаються, зміст переходить до розділів).
6. Якщо Android CI пройшло, але phone QA ні — зазначати це, не називати функцію прийнятою.
7. Перевірити пріоритетні open issues: `PERF-NAV-002` (підвисання переходів), `BUG-EXPORT-001` (завершення процесу повного експорту на ~48%), `PERF-PLAYER-001` (нерівномірний рух).

**Поточний принцип найменувань:** GF у вихідному коді поки означає комплект героя Shark/Panther; «Аудіоформи» — лише новий майбутній тип, не синонім існуючого GF. Документ `docs/architecture/VISUAL_ELEMENTS_TAXONOMY.md`.
