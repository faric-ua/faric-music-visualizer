## 2. Експорт MP4 — як працює зараз

Повний опис з точними значеннями — `docs/export/EXPORT_ETALON.md`. Коротко:

1. **Офлайн-аналіз пісні** (кнопка в Export Lab, вручну перед кожною піснею) → «сигнал» на кожну мить: бас, середина, верх, удари.
2. **PCM-кеш** для projectM (декодування всієї пісні в моно-файл).
3. **Кадр за кадром** (30 за секунду, час кадру розрахований, а не реальний): projectM + шари → кодер H.264 через Surface. 4 шляхи (А — повний GPU, Б — projectM через копію, В — без projectM, Г — старі теми).
4. **Потім** звук AAC 160 кбіт/с → **потім** збирання відео + звук у `Movies/FARIC`.

**Швидкість (найкраще заміряне, v0.19.22):** 3 с відео за 5,45 с → ~60 мс на кадр → пісня 4 хв ≈ 7–8 хв.
Де йде час (шлях А, 90 кадрів): композиція на CPU 2306 мс (з неї **HUD ~1080**), накладання прозорих шарів на GPU 503–700, кодер 684, projectM 672.

## 5. Пакетна обробка («завантажив пісні — у фоні вийшли відео»)

Що потрібно (по черзі, кожне — передумова наступного):

1. **Уся пісня має доходити до кінця** (V1) — без цього пакет не має сенсу.
2. **Фонова служба експорту** (Android: foreground service, тип `mediaProcessing` на Android 15+ / `dataSync`) зі сповіщенням «Відео 3 з 10 · 45 %», кнопка «Зупинити». Експорт не залежить від екрана (Р1); поворот і згортання не заважають (V2).
3. **Знімок композиції** («сцена»): усі ввімкнені шари, їх налаштування, вибраний пресет projectM, формат — зберігається як файл; пакет бере один знімок для всіх пісень (або свій для кожної).
4. **Черга:** вибрати пісні / альбом / папку → для кожної: аналіз → PCM → відео → звук → файл. Черга переживає перезапуск; одна пісня впала — інші йдуть далі, у звіті видно чому.
5. **Обкладинка й назва пісні** у відео (з тегів файлу; задумка V22 — разом з Audio Converter).
6. **Окремий projectM для експорту** (Р4) — щоб можна було дивитись візуалізатор, поки пакет рендериться. Без цього — пакет лише коли застосунок «відпочиває».
7. Готові відео — у `Movies/FARIC/<назва пакета>/`, назва файлу = назва пісні.

Обмеження, про які чесно сказати: телефон гріється (7–8 хв на пісню → альбом з 10 пісень ≈ 1,5 год); на зарядці краще; одночасно кілька пісень — ні (кодер і GPU одні).
