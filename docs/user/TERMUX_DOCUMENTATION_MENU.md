# FARIC · Documentation у меню Termux

**Для кого:** користувач FARIC / тестувальник Android APK.  
**Статус:** додано як окреме підменю Termux; зміни лише у скриптах та документації, **Android APK не змінено**.

## Головне меню

Тепер унизу є один додатковий пункт:

```text
DOCUMENTATION
20 — Documentation →
0 — Вийти
```

Номери попередніх команд **1–19 не змінювалися**. Скрипт головного меню: `scripts/termux-menu.sh`. Вкладене меню: `tools/termux/documentation-menu.sh`. Безпосередній запуск також можливий командою `bash tools/termux/documentation-menu.sh` з кореня репозиторію.

## Підменю Documentation

| Номер | Дія | Уточнення |
|---|---|---|
| **1** | **HTML** | Спочатку шукає імпортований HTML зі скриншотами. Якщо його немає, **автоматично створює автономну HTML-довідку** з актуального GitHub Markdown і вбудовує зображення з репозиторію. Обидва варіанти працюють офлайн. |
| **2** | **PDF** | Відкриває локальний PDF у встановленій Android-програмі. |
| **3** | **DOCX** | Відкриває локальний DOCX у Word або іншому сумісному редакторі. |
| **4** | **Актуальний посібник GitHub** | Відкриває `docs/user/FARIC_USER_GUIDE_UK.md` через браузер. Це актуальна текстова редакція в GitHub; для перегляду потрібен інтернет. |
| **5** | **Інші документи проєкту →** | Додаткове компактне підменю для `docs/`, Героїв/Аудіоформ, аналізу відео, плану робіт, findings та release checkpoints. |
| **6** | **Імпортувати ZIP / файли з Downloads** | Одноразовий імпорт раніше наданого комплекту або окремих PDF/DOCX/HTML із Downloads у постійну папку. |
| **7** | **Відкрити папку Documentation** | Пробує відкрити точну папку Android або показує шлях для ручного переходу. |
| **0** | **Назад** | Повертається до основного меню без дублювання процесів. |

## Перший запуск / імпорт

1. **Для HTML ZIP не потрібен:** після оновлення проєкту просто відкрий **Termux → 20 → 1**. Якщо імпортований HTML відсутній, довідка збирається з `docs/user/FARIC_USER_GUIDE_UK.md` і зберігається поза Git у кеші Termux.

   **Для PDF, DOCX або оригінального HTML зі скриншотами** завантаж раніше переданий файл `FARIC_User_Guide_UK_v0.19.43_COMPLETE.zip` із чату. Розпаковувати його не потрібно.
2. ZIP повинен лежати у стандартній папці Android `Download`. Працює також із окремими файлами `FARIC_User_Guide_UK_v0.19.43.pdf`, `.docx`, `.html` у Downloads.
3. **Termux → 3** — онови GitHub-проєкт (одноразово після додавання підменю).
4. **Termux → 20 → 6** — імпортуй комплект. Скрипт читає тільки файли з дозволеними назвами та не дозволяє ZIP розпакувати файли поза папкою Documentation.
5. Надалі **Termux → 20 → 1/2/3** одразу відкриватиме відповідний формат, а **20 → 1** працює навіть без імпорту.

Постійна папка:
`/storage/emulated/0/Documents/FARIC-Music-Visualizer/documentation/v0.19.43/`

Для наступних версій файли зберігатимуться в окремій `vX.Y.Z/` папці. Підменю відкриває найновішу знайдену версію формату. Усі документи видно через звичайний файловий менеджер Android.

**Якщо файл не знайдений:** пункт друкує інструкцію імпорту, але не вдає, ніби PDF/DOCX вже завантажені. GitHub Markdown (пункт 4) доступний окремо. Немає автоматичних інсталяцій Termux-пакетів, перезапуску застосунку, зміни APK або роботи з приватними даними.

## Підтримка

- Авторитетний текст посібника: `docs/user/FARIC_USER_GUIDE_UK.md`. Правила редагування: `docs/user/README.md`.
- Коли змінюється посібник, **локально згенерований HTML** оновлюється при наступному запуску `20 → 1`. Імпортований HTML, PDF та DOCX зі скриншотами залишаються файлами своєї версії — для оновлення їх потрібно перевидати та імпортувати новим ZIP. Markdown на GitHub завжди є актуальним джерелом.
- При розширенні Documentation додавати варіанти **тільки у вкладене меню**, а в основному залишати один пункт 20.
- Перед релізом скриптів виконати `bash -n tools/termux/documentation-menu.sh`, перевірити Python-імпортер та CI `Validate`.
- Майбутній UX finding: виправити пропорції зображення акули на обкладинці PDF, показані на скриншоті користувача 2026-10-08. Це **дефект оформлення PDF**, а не деформація героя всередині Android.
