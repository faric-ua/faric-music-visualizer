# Reference Analysis — Interaction Patterns Only

The supplied screenshots were used only as interaction references.

Useful general patterns observed:
- persistent bottom mini-player;
- category-based media library;
- folder and album browsing;
- context menus;
- multi-select;
- search;
- equalizer;
- full-screen player;
- queue/shuffle/repeat;
- metadata-oriented rows.

Elements we intentionally do **not** copy:
- exact screen composition;
- exact icon placement;
- exact typography hierarchy;
- exact transport geometry;
- branding;
- specific menu arrangement;
- equalizer visual styling.
