## Engineering changes
- `MainActivity`: persistent `persistentSceneRoot` with the original `PulseDeckLayerStack` and live `ProjectMView`.
- `Board`: new editor UI added above same scene, same `HeroBoardView` edited in place; Board controls may be recreated but GL, GF and other composition layers are retained; exiting removes only UI and restores HUD/GF visibility.
- `projectM`: installed-library route no longer launches separate ProjectMActivity; uses live overlay on existing native view. Temporary visibility mask hides unrelated composition layers, restored on exit. TOP/ALL/NEXT/FG/BG/CENTER/EDGE/⚙ FG and AUTO interval authoring available; first-time missing native library can still open legacy installer activity.
- `Theme Picker`: opening and cancelling browser overlays retained player scene; selecting changed theme may still intentionally rebuild underlying render components, which remains a follow-on optimization.
- `ProjectMSettingsPanel`: AUTO changes now update in-overlay timer. Existing IDs and stores untouched.
- `FARIC-nav` logs report overlay open/close and retained scene; `ProjectMView` existing native creation logs can be counted during test.
