# PulseDeck v0.19.63 / build152 — native Android system bars always visible by default

**Release status:** signed MAIN CI PASS / Android #683; **phone QA not yet done**.

## User requirements

1. **Android native status bar (top) and system navigation/gesture bar (bottom) should always be visible by default**, rather than requiring swiping downward/upward to make transient immersive bars appear. Apply to all screens, including Board, GF Mix, playback, Theme picker, Export/Export Lab, main Library, projectM focus, calibration, Template Constructor, Object Constructor. The operating system still decides navigation **style** (3-button vs gesture), icon rendering and system-owned behavior; app only stops hiding these bars.
2. **Settings option:** PulseDeck live player → tools/menu → **«Системні панелі Android»** → choose **«Завжди показувати верхню та нижню панелі»** (default, stored) or **«На весь екран, як раніше»** (opt-in legacy immersive mode). Toggling must not restart audio or projectM, replace live renderer or mutate composition.
3. **User-facing ChatGPT phone test checklists (not app native UI):** high-contrast **RED circle for unchecked / not verified**, **GREEN circle with check mark for confirmed PASS**, large 36px or larger touch targets, progress counter and a large **«Надіслати результат»** button. Do this by default in subsequent PulseDeck testing turns, since user confirmed this is legible outdoors in sunlight. No claims that ChatGPT presentation itself becomes an Android app setting.
4. **Export screen included**. Current Export Lab shows aspect ratios 9:16/16:9/1:1/4:5, PNG still frame, offline analysis and MP4 controls. Bar visibility applies here too, not only Board. The user mentioned 'експорт даних'; don't conflate this with creating a new unrelated data-export workflow without further specification.

## Implementation

- New `PulseDeckSystemBars.kt` owns key `faric.system_bars_always_visible` in existing `faric.preferences`; no stored value defaults to **true**. `WindowCompat` shows/hides `systemBars()`, setting readable light-on-dark icon appearance and requesting insets; never uses legacy sticky immersive flags when set visible.
- `MainActivity.enableImmersiveFullscreen()` now consults the shared setting, so all existing screen transitions are covered (player/Board/Theme/Export). On focus, prefer visible bars; Library and projectM already favored bars. Main `applySafeArea` accounts for visible status/nav/IME insets on controls; the **full-size master plate remains anchored to its immutable physical-coordinate calibration** rather than globally shifted.
- Template Constructor, Object Constructor, Calibration migrated off local legacy `SYSTEM_UI_FLAG_HIDE_NAVIGATION/FULLSCREEN/IMMERSIVE_STICKY` and call the common helper on create and focus. `ProjectMActivity` previously already showed system bars and supplies its own safe-area padding; preserve it.
- Visualizer, graphics, MP4 render dimensions, playback controls and source assets are unaffected. Exported video still excludes native system UI.
