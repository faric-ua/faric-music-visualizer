# FARIC PulseDeck — accepted skin prototype

Status: **APPROVED AS VISUAL BASELINE**  
Date: 2026-09-28

Canonical repository prototype:

- `PULSEDECK_SKIN_V1.svg`

This vector prototype records the skin direction approved in the project chat:

- deep black / graphite background;
- orange + cyan dual accent;
- luminous central PulseCore;
- radial audio spectrum;
- flowing ambient waves;
- large central playback control;
- Scene / EQ / Effects shortcut row;
- persistent PulseDock;
- bottom Library / Visualizer / Search / Queue navigation;
- rounded glass-like surfaces.

The SVG is a FARIC design source. It is not a screenshot of another application and is not a request to clone Poweramp.

## Versioning rule

Future UI work should preserve this identity unless the user explicitly approves a new skin version.

When the visual language changes substantially, create a new immutable prototype:
`PULSEDECK_SKIN_V2.svg`, etc. Do not silently overwrite V1.
