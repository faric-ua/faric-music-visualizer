# Release Documentation Contract

For each release:

```text
docs/v.X.Y.Z/
├── RELEASE_META.json
├── RELEASE.md
├── REGRESSION_CHECKLIST.md
├── diagrams/
│   └── README.md
└── qa/
    ├── BUG_REGISTER.md
    ├── PHONE_TEST.md
    └── EVIDENCE_MANIFEST.md
```

Track source, CI, APK and phone QA separately.
