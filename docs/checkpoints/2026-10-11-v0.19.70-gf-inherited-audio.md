## Root cause of phone FAIL
- Prior `BoardGroupReaction` animates the entire GF canvas while independent child controls default to 0/0/0. It creates false UI readings and additive/double movement; built-in `BoardLayerReaction` may also still react to beat when child values are zero.
- `layerTitle(CREATURE)` was derived from a backing native theme ID `CYBER_PANTHER`, not the active external Scorpion PNG, so `Panther` was displayed.

## New source-level contract
1. Group parent `Усе GF` holds one triplet (rotation/stereo/bass) as a *preset*, not a second physical GF reaction. Renderer group reaction is neutral.
2. Each child FRAME/FX/CREATURE/WORDMARK has its own **absolute** music response. Missing legacy preferences inherit current parent values; explicitly stored child values win. Changes to ANY parent slider broadcast the FULL triplet to all four roles, overwriting old child overrides. Child editing updates only its own preferences.
3. No 0/0/0 music motion: clear legacy baked-in audio amplitude/bass/mid/high/beat scale/alpha/beat rotation/beat Y coefficients when applying the new per-child absolute music response. Never erase manual geometry, frame auto-spin or ProjectM background animation as these are not child music reaction.
4. Board `CREATURE` label is now **Герой**, irrespective of source theme name. The source file names and opaque IDs are not renamed.
5. CPU/GPU video config and live `HeroBoardView` both load the same parent-inherited child values; no physical double application of parent. Reset GF sets parent + all children to same defaults; Composition Set parent import broadcasts to children.
