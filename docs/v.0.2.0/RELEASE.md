# v0.2.0 — PulseDeck Shell

## Goal

Replace the temporary single-purpose visualizer screen with the first real FARIC PulseDeck player shell.

## Scope

- original FARIC dark/neon skin;
- Library landing screen;
- persistent PulseDock mini-player;
- full Now Playing screen;
- current reactive scene reused as PulseCore;
- seek bar and elapsed/total time;
- play/pause;
- initial navigation placeholders for Library / Visualizer / Search / Queue;
- action placeholders for Scene Lab / Tone Lab / Queue;
- keep local file picker and current playback working.

## Explicitly not yet in this release

- full media scanner;
- album/artist/genre/year database;
- real queue implementation;
- next/previous across a library;
- equalizer DSP;
- YouTube backend;
- YTM integration.

Those remain separate phases and must not be presented as implemented.

## Reference rule

The supplied Poweramp screenshots are interaction references only.

v0.2.0 must not copy:
- exact layout;
- branding;
- icon geometry;
- menus;
- equalizer styling;
- transport geometry.

The accepted design language is FARIC PulseDeck:
PulseDock / PulseCore / Library Worlds / Orbit Rail / Tone Lab / Scene Lab.
