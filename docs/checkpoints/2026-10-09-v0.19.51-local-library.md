# v0.19.51 / build 140 — Local Media Library foundation

## Reason for this release
The existing Home/Library is already an implemented UI but its eight category
cards show only placeholders. Search buttons show toasts. PlaybackController
already supports full multi-track Media3 queues. This release connects one
useful end-to-end slice **without** rebuilding the home UI or the projectM
persistent rendering scene.

## Scope
- Android permissions: READ_MEDIA_AUDIO (API 33+), READ_EXTERNAL_STORAGE
  through API 32 only. Do NOT require library permissions to use the existing
  explicit SAF audio picker.
- Add read-only MediaStore audio scanner: title, artist, album, duration and
  content URI. Scan asynchronously off the UI thread.
- Home «Усі треки» -> functional scrollable ListView, with title + artist +
  duration; search by title/artist/album; on selection load the *visible,
  filtered* queue using the existing PlaybackController and open Now Playing.
- Home search icon and bottom-navigation «Пошук» -> same library browser with
  search focused. Activity tracks screen state; Back -> Home; rotation reopens
  library browser without triggering playback.
- Read permission is requested **only** through an explicit action on the
  browsing screen. Denial leaves an option to select music via SAF.
- Keep already existing Home cards for Albums, Artists, Folders, Genres,
  Years, Favorites, Recent as non-destructive placeholders for subsequent
  foundation stages. Never present them as implemented in v0.19.51.
- Existing mini-dock/player controls and projectM/GF/Skin calibration are
  not modified; full-song BUG-EXPORT-001 and phone navigation PERF-NAV-002
  remain independent/open.

## QA gates
1. Unit test LocalMusicSearch (title, artist, album, trimming/empty search).
2. Android debug APK CI build/signature PASS; verify source commit.
3. Phone: Home «Усі треки» displays correct device audio count after
   granting permission; denial does not crash; new permission scopes right.
4. Search by title/artist/album filters rows; selecting song plays it and
   Next follows filtered list; no accidental auto-play on mere browsing.
5. Back from track list returns Home. Search screen survives rotation; no
   duplicate playback session or GL initialization; existing player/Dock
   still functional.
6. 3-second MP4 is an independent regression check, not silently accepted.

## Next scope after phone PASS
Albums / Artists / Folders / Favorites / Recently played based on one
grounded indexed music catalog, followed by a refreshed Home page using
actual counts and state. Offline library and online media should not be
mixed. Avoid inventing track metadata or drawing placeholder covers as real.
