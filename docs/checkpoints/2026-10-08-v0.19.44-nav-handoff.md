## Source changes in build 133

1. **Board ↔ Player:** `MainActivity.deferMainProjectMRebuild(target)` queues `ProjectMView.releaseProjectMThen` on the existing GL thread, waits for completion via callback, then recreates the requested screen. This replaces the UI-thread `releaseProjectMBlocking(1500)` for that specific route. Repeat requests coalesce to last destination. Native singleton ownership is retained (never simultaneously create old/new projectM bridges).
2. **Separate projectM → Player return:** ActivityResult restores **only** `PulseDeckLayerStack.Layer.VISUALIZER` into the retained player layout instead of re-running `showNowPlaying()` and rebuilding all PulseDeck/HUD/GF layers.
3. **Timing instrumentation:** `FARIC-nav` logs async release and slot-restoration elapsed times; `FARIC-projectM` logs native queue wait, destroy, init and first rendered frame.
