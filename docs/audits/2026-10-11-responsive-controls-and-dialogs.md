# PulseDeck — UI/UX audit: spacing, wrapping and responsive controls
**Recorded:** 2026-10-11. **Status:** AUDITED IN SOURCE / BACKLOG OPEN; **no UI code change in this audit.**
**Source baseline:** main app/source v0.19.62 / build151, `75433e0728d8a75006deb67826851ef0fbdb2245` (subsequent docs-only commits possible).
**Scope:** EVERY settings/controls screen and dialog, not just GF Mix. Findings below are *source-verified examples*, not proof every screen has been visually inspected. Full-device dynamic QA and layout inventory remain an explicit second step.

## User request / intended contract
- Clear, consistent **space BETWEEN buttons and between tiles**, not a tight, stuck-together stack; sufficient breathing room around headings, groups, selectors, sliders and action footers.
- ALL button/option labels must remain readable. If a label does not fit on one line, **wrap naturally to 2+ lines** and **increase that button/tile and, where needed, the containing row/panel height proportionally to measured content**. Never allow text to protrude outside borders, overlap neighboring controls, be clipped by fixed dp heights, or silently lose essential meaning in ellipses.
- Make control dialogs compact **but scrollable** when long, leaving important action/cancel navigation accessible. No giant dialogs stretching under system bars.
- Apply to: Settings; Board editor; GF Mix source lists/templates; PNG folder + source selectors; Theme Picker / Hero catalog; other app-controlled modal windows; projectM Settings panel; relevant export, diagnostics and Help screens.
- Preserve user data, graphics, gesture handlers, button actions, selected GF sources and existing state. **Do not treat a screenshot alone as permission for an unreviewed large refactor.**

## Proposed spacing tokens (design baseline, not implemented)
- **4dp:** tiny inline icon–label/secondary adornment space only.
- **8dp:** minimum gap for closely related repeated small controls and source-picker rows.
- **12dp:** default inter-button / inter-card spacing for normal settings modal buttons, multi-column tiles, list rows.
- **16dp:** gap between logical sections/groups; 16–20dp horizontal panel padding; 12–16dp touch-button horizontal padding.
- **24dp:** separation between major panels or independent groups, when space allows.
- Use `minHeight = 48dp` interactive controls; **primary action minHeight 52–56dp**. Heights otherwise `WRAP_CONTENT`; 2-line labels grow to natural measured height with vertical padding; longer text is still accessible, either via fully wrapping control or safe detail view. Never solve overflow by squeezing font below accessible sizes.
- Multi-column tiles should have a consistent **12dp** gutter and shared row height based on the tallest wrapped card. Use single column on narrow screens/fontScale if the paired cards would become cramped; allow natural dynamic width/height.
- Convert existing 42/43/44/78/205dp **fixed heights** only where text growth makes them unsafe (icons/previews may retain aspect ratio). A row composed of thumbnail and text grows to `max(previewHeight, textHeight)`, image centered vertically.
- Text: normal word wrap, high-quality line breaking (where supported), allow full button labels instead of clipping; accessible semantic labels. `ellipsize` allowed *only for optional metadata* when there is a clear path to read the full value, not for primary actions.
- Dialog: size within visible screen after system navigation/status insets and keyboard; scroll long action list/body, with reachable Back/Close and primary action footer. All dialogs must remain usable on rotation without launching operations twice.
