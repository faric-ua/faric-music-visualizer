## User-visible feature

In the existing Board editor tap **«◆ GF Мікс · обрати свої PNG»**. Choose each separate source:

- `FRAME`: frame from any installed hero pack
- `FX`: electric/particle effects from any installed hero pack with a real FX part
- `CREATURE`: any installed hero graphic
- `WORDMARK`: FARIC / FMV / FVMP matching the original source art

Selection shows immediately on the retained live GF view without a GL / Audio / HUD rebuild; bitmap decoding is performed off the UI thread. Save as a named GF preset, reopen it from the same dialog, continue editing a working copy, or restore the original figure. Edits to X/Y, scale, rotation, frame auto-spin, opacity and object visibility for an active mix are saved in the mix draft rather than mutating the original source Hero preferences. A separate composition still references the original immutable artwork by `sourcePackId + type`.

All 4 selected artwork references are forwarded to `CyberSharkExportConfig.assetOverrides` and consumed by `CyberSharkExportRenderer` in both Canvas and GPU paths; no per-frame bitmap decode and no silent source substitution for missing artwork. The on-device render path still uses the established `HeroBoardView` layer motion engine. The global PulseDeck z layers and `PULSEDECK_CENTER_CALIBRATION` are untouched.
