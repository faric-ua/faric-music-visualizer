## Source scope

1. **Real embedded album art:** `LocalAlbumArtwork.kt` decodes locally embedded cover JPEG/PNG from MediaStore `content://` audio using `MediaMetadataRetriever`, off UI thread via 2 bounded workers, max 40 pending and LruCache ~20MB. Recycled row views use exact URI tags to prevent wrong cover flashes; no artwork uses a neutral placeholder. Android API26-compatible explicit `release()`; no internet/network cover search. Albums and song rows display covers.
2. **Real artist+album in player:** optional `QueueTrack.artist/album`, Media3 `MediaMetadata` propagated to `PlaybackSnapshot.trackArtist/trackAlbum`, player HUD/mini dock and GF hero metadata instead of hardcoded unknown. SAF-only files without tags still fall back gracefully.
3. **Manual playlist sequencing:** previously playlists were title-sorted by default, obscuring persisted order; default now `PLAYLIST_ORDER`. Long-press playlist group to rename; long-press a song to move it Up/Down or remove; old create/add/remove/delete behavior retained. No audio files altered.
4. JVM tests: manual order retained, up/down boundaries, missing track/zero delta unchanged.
