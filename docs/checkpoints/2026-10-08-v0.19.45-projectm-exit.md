## Source audit and narrow fix

Both Back controls call ProjectMActivity.exitToPlayer(). Before v0.19.45 the exit method nulled projectMView before the Activity onPause could pause its GLSurfaceView. Even though native destroy is queued, continuous old GL drawing may race the new ProjectMView after ActivityResult restores the player. This is a credible code ownership race, not a proven explanation for phone stutter without logs.

- ProjectMView: volatile releaseRequested set before each native release call; renderer skips draw and onSurfaceChanged when release was requested.
- ProjectMActivity: retain reference during native release, explicitly pause old view before finish(), then clear field; measure release and GL pause in FARIC-nav.
- No UI label changes or changes to MP4 encoder. Do not assert performance PASS from source/CI.
