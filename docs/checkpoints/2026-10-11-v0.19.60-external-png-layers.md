# PulseDeck v0.19.60 / build149 — external PNG thumbnails and four independent source libraries

## Regression report
- v0.19.59/build148: user successfully indexed all ten PNG creatures through `Зовнішні PNG-герої` but no thumbnails appeared in the old Theme catalog; pressing legacy "СКОРО" cards still reported that a *prepared hero pack* was required. The old Theme cards use legacy prepared full/4-layer WebP assets and do **not** auto-map uploaded separate PNG creatures. The new external picker originally showed plain text buttons, no preview ImageViews.
- User also wants **separate import of wordmark (FARIC / FMV / FVMP), frame, FX**, not just creature, with all artwork left **external** rather than bundled in APK.

## New implementation
- `MainActivity`: each external PNG gets a real small `ImageView` thumbnail in the existing `Зовнішні PNG-герої` dialog and also a clearly labeled two-column **«Мої зовнішні PNG»** section before the legacy cards inside the expanded Theme Hero catalog. Thumbnails decoded off the UI thread at sample sizes targeting 128/192 px; only selected creature is decoded at full resolution for the active player.
- `ExternalPngHeroLibrary`: four independently remembered **read-only SAF folders**: Creature, Frame, FX and Wordmark. The pre-existing creature index key `items` / folder key `tree_uri` is preserved for lossless build148 migration. Typed indexes use `items_frame`, `items_fx`, `items_wordmark` and their respective `tree_uri_<type>` keys. No PNG is copied into app data.
- `GfAssetLibrary`: stable source ID + role filter. External PNGs can be selected as **Frame, FX, Creature or Wordmark** in GF Mix. The existing independent per-object transforms/visibility and export source references remain.
- `GfMixController`: source menu for each role ends with **«＋ Додати PNG для ... із папки»**. On Android's SAF folder selection, the app validates PNG magic bytes and transparency, remembers the role's folder, and returns to GF Mix; user selects the imported file under the chosen role.
- Validity is based on actual PNG image format (not renamed JPEGs). Two scorpion versions remain separate. Existing selected Hero, 10 PNG records and saved GF Mix presets must not be deleted or migrated away.
- **Separate PNG files are required for the separated visual objects**. A combined emblem PNG containing text + frame + hero is *not* magically separated by the app.
- Runtime memory: off-APK storage reduces APK size and idle cache, but a selected 1254×1254 ARGB hero still uses approximately 6 MiB decoded pixel storage plus transient GPU texture overhead.
- Keep unchanged: `PULSEDECK_CENTER_CALIBRATION`, legacy packaged Cyber Shark/Panther, projectM renderer lifetime, existing MP4 export pipeline, `BUG-EXPORT-001` and `LIFE-ROT-001` open.

## Android folder organization (example)
- `Documents/PulseDeck_Heroes/` — existing ten hero PNGs; keep the previously indexed folder in place.
- `Documents/PulseDeck_GF/Frames/` — independent frames as transparent PNG.
- `Documents/PulseDeck_GF/Wordmarks/` — standalone FARIC/FMV/FVMP wordmarks as transparent PNG.
- `Documents/PulseDeck_GF/FX/` — optional PNG electrical/fire/neon effects.

User can create folders themselves in the Android Files app; app gets read-only SAF grants per selected category.
