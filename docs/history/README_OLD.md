# FARIC Music Visualizer

Android-first audio-reactive visualizer.

Goal: play music and render a full-screen scene that reacts to rhythm, energy and spectrum:
- animated image/video/procedural backgrounds;
- central orb/logo/cover element;
- beat-synced pulse, glow, radial waves and particles;
- scene presets;
- later: generated backgrounds and optional video export.

Repository: `faric-ua/faric-music-visualizer`

Package ID reserved for Android scaffold: `com.saney.musicvisualizer`.

## Status

Foundation / planning stage. No production Android app yet.
