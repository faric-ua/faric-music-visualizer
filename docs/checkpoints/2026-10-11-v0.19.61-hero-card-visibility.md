# v0.19.61 / build150 — hide unusable prepared-Hero placeholders in Theme Picker

## User report
User screenshot (2026-10-11) of Theme → Heroes shows Cyber Shark, Cyber Panther and multiple **empty** legacy cards labelled `СКОРО` (Saber Tiger, Thunder Wolf, Arcane Specter, Inferno Phoenix, etc.). These are not imported user PNGs. The old `PlaybackThemeRegistry.all` loop created a card even for an uninstalled `UserHeroPack` future-theme slot, generating a 248dp tile with an empty preview and a non-functional `Потрібен підготовлений пакет` click handler. This is **not evidence** that the ten existing SAF external PNG records disappeared.

## Change
- In `MainActivity.showThemePicker()` render only **installed legacy Figure themes**; skip `figure && !GraphicFigureCatalog.isInstalled(...)` *before* creating its card and preview. This preserves non-Hero themes (including built-in non-graphic themes) and installed Cyber Shark/Panther.
- Replace wrong fixed `GraphicFigureCatalog.ids.size + externalCount` header by **installed Figure count + externally indexed CREATURE PNG count**. Count is updated on each Theme Picker recreation and preserved when expanding/collapsing the section.
- Existing installed original themes, external `Мої зовнішні PNG` thumbnails, SAF grants, 10 indexed source images, layer presets, source pack metadata and app data are untouched.
- Keep **`＋ Додати підготовлений пакет героїв`** action: upon later user import of a complete package, its tile reappears automatically. No deletion or breaking future Hero support.
- **Cyber Panther** is an installed built-in choice, not a `СКОРО` placeholder; its specific preview appearance, if still blank on phone, needs a separate targeted art/preview audit rather than silently treating it as a missing package.
- Avoid changing `PULSEDECK_CENTER_CALIBRATION`, projectM/player lifecycle, audio, GPU, export, and source PNG bytes.
