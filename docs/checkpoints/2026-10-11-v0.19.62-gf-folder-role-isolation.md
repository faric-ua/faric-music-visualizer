# PulseDeck v0.19.62 / build151 — SAF PNG import role isolation

## Phone report and diagnosis

User screenshots show:
- Board GF Mix selects Frame «Cyber Shark», FX «Cyber Panther», Creature displayed as a filename beginning `file 000...`, and Wordmark «Cyber Panther»;
- Hero catalog still has valid thumbnails for both scorpion A/B and an external Hero list;
- Board live preview shows a ring but not the expected creature on the chosen setup.

User says selecting a folder to add FRAME artwork caused images to be indexed under Heroes instead.

Code-level root cause **confirmed vulnerability** in MainActivity v0.19.60–61: `pendingExternalPngType` was an Activity field initialized to `GfArtType.CREATURE`, set immediately before an external Android `OpenDocumentTree` Activity. If MainActivity was recreated by Android while the system picker was active, that field reset to CREATURE, and the returned FRAME folder was scanned into `ExternalPngHeroLibrary.items/tree_uri` (CREATURE category), overwriting that catalog. A reproduction on user's device is not yet proven, but source flow definitely permitted it.

## Changes

- Persist the **exact** import role in a dedicated small SharedPreferences record with synchronous `.commit()` **before** opening the SAF picker.
- On result, **read and clear** the pending role. If absent/invalid, fail closed with an explanatory message instead of defaulting to CREATURE. Cancel leaves indexes untouched.
- `ExternalPngHeroLibrary.scanFolder` refuses to use a tree URI already assigned to a **different** GF type, before updating any saved entries. This prevents mistakenly reusing the existing hero folder as Frames/FX/Wordmarks.
- After scanning FRAME / FX / WORDMARK, immediately reopen that type's **source selector**, label the result, and ask for explicit selection. No automatic Creature selection. Explicitly selecting an asset makes its own layer visible, including after a standalone Hero view had hidden the other three.
- Keep original user PNG bytes in selected SAF folders (none added to APK), existing GF presets, original calibration and projectM state untouched. No deletion/migration of previously indexed assets.

## Important data safety note

If an older buggy app already overwrote the CREATURE index, **the original PNG files on disk remain untouched**, but their stored URI list may need repair by explicitly choosing the original `Documents/PulseDeck_Heroes` folder again. Do not claim that a previously overwritten index can always be magically restored; inspect the current list first. If original ten thumbnails remain, do **not** reimport. Existing intentional GF Mix source selection must not be erased.
