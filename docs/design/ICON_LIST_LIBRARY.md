## Як вставляти готові іконки

Кожна — окремий PNG з прозорим фоном, квадрат (напр. 192×192), значок по центру, однакові поля. Назва файлу — номер і слово з таблиці (`01_search.png`, `13_favorite.png`…). Застосунок малюватиме їх по центру кола / плитки однакового розміру.
